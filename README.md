## التشغيل محليًا

الموقع واجهة ثابتة تعمل عبر أي خادم ملفات محلي. من جذر المشروع شغّل مثلًا:

```bash
npx serve .
```

ثم افتح عنوان localhost الذي يعرضه الخادم.

## الخادم الخلفي

الخادم الخلفي موجود في مجلد [`server/`](./server/) لكنه معطّل حاليًا؛ الواجهة الأمامية تعمل محليًا دون الاعتماد عليه.
