## 🇬🇧 English

### 📖 About the Project

**MaktabaPlay** is an independent educational web platform that transforms core **Library and Information Science (LIS)** concepts into interactive games and hands-on learning experiences.

Initiated in **2025** as a solo personal project, MaktabaPlay is an evolving platform continuously refined through iterative development stages, structural refactoring, UI/UX enhancements, and curriculum-aligned content updates. Its core mission is to make library science concepts more engaging, accessible, and enjoyable through **gamification**.

### 🎮 Educational Games & Modules

The platform currently features **nine** interactive learning experiences covering cataloging, classification, library management, and archival terminology:

| # | Game / Module | Focus Area & Description |
| :-: | :--- | :--- |
| **1** | **Book Detective** | Explore bibliographic records and solve cataloging-related challenges. |
| **2** | **Library Tycoon** | Experience library administration and resource management through an interactive simulation. |
| **3** | **Classification Ladder** | Progress through classification challenges with escalating difficulty levels. |
| **4** | **Shelf Sorter** | Practice organizing, shelving, and arranging library materials accurately. |
| **5** | **Index Tree** | Explore core concepts of indexing, taxonomy, and information organization. |
| **6** | **Classification Race** | Test your speed and accuracy in classifying subjects under time pressure. |
| **7** | **Quick Training** | Reinforce library science concepts through bite-sized interactive drills. |
| **8** | **User Guide** | Interactive onboarding module to navigate and master the platform's features. |
| **9** | **Manuscript Hangman** | Master specialized library and manuscript terminology via a word-guessing game. |

> *Note: Game mechanics, question banks, and modules are subject to continuous expansion and refinement.*

---

### 🎯 Project Objectives

* **Simplify LIS Concepts:** Break down complex cataloging, indexing, and classification standards into intuitive formats.
* **Encourage Active Learning:** Shift from passive reading to hands-on, gamified problem-solving.
* **Build Practical Familiarity:** Strengthen students' command of bibliographic records and shelf organization.
* **Reinforce Terminology:** Introduce domain-specific library and manuscript vocabulary in an engaging context.
* **Open Educational Access:** Provide a free, browser-based learning tool for LIS students and enthusiasts.

| :-: | :--- | :--- |
| **1** | **Book Detective – محقق الكتب** | استكشاف التسجيلات الببليوجرافية وحل تحديات مرتبطة بالفهرسة. |
| **2** | **Library Tycoon – مدير المكتبة** | تجربة إدارة المكتبات وتنظيم الموارد من خلال محاكاة تفاعلية. |
| **3** | **Classification Ladder – سلم التصنيف** | التدرج في حل تحديات التصنيف بمستويات صعوبة متصاعدة. |
| **4** | **Shelf Sorter – منظم الأرفف** | التدريب العملي على تنظيم وترتيب المواد المكتبية على الأرفف. |
| **5** | **Index Tree – شجرة الكشافات** | استكشاف المفاهيم المرتبطة بالتكشيف وتنظيم المعلومات. |
| **6** | **Classification Race – سباق التصنيف** | اختبار القدرة والسرعة في تصنيف الموضوعات المختلفة تحت ضغط الوقت. |
| **7** | **Quick Training – التدريب السريع** | ممارسة مفاهيم المكتبات من خلال أنشطة وتدريبات تفاعلية قصيرة. |
| **8** | **User Guide – دليل المستخدم** | دليل تفاعلي للتعرف على كيفية استخدام المنصة والتنقل بين أقسامها. |
| **9** | **Manuscript Hangman – المشنقة والمخطوطات** | تعلم مصطلحات المكتبات والمخطوطات من خلال لعبة تخمين الكلمات. |
